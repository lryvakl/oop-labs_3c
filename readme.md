# Lab 2
### Варіант 2: Алмазний фонд. Дорогоцінні та напівдорогоцінні камені, що містяться в павільйоні, мають такі характеристики:
• Name – назва каменю.

• Preciousness - може бути дорогим або напівдорогоцінним.

• Origin – місце добування.

• Visual parameters (має бути кілька) – можуть бути: колір (зелений, червоний, жовтий тощо), прозорість (вимірюється у відсотках 0-100%), способи огранювання (кількість граней 4-15). 

• Value – вага каменю (вимірюється у каратах). 

Кореневий елемент називається Gem.
